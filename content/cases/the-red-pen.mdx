## THE BRIEF

Tutors were spending about an hour marking each assignment by hand against dense qualification criteria — and it only got slower as enrolments grew.

## THE OPERATION

Designed an AI marking tool end to end: defined the prompting approach and built the training database by importing each qualification's specification — learning outcomes and assessment criteria, unit by unit — then led testing across providers (DeepSeek, OpenAI) behind daily cost caps and a human review queue for low-confidence results. Automated learner enrolment form-filling along the way. Marking dropped from 60 minutes to 20 per assignment.
