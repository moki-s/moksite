# Mokisite Features and Roadmap

This document outlines the proposed design and feature set for the personal portfolio website based on the provided resume. 

## Vibe & Aesthetics
- **Theme**: Vibrant, Playful, and Dynamic.
- **Micro-interactions**: Hover effects on cards, floating skill bubbles, and smooth scroll transitions to make the site feel "alive."
- **Color Palette**: We will define a custom, modern color palette using CSS variables (e.g., deep purples, bright accents like neon green/pink, or a glassmorphism dark mode).

## Core Technologies
- **Framework**: React (using Vite for fast builds).
- **Styling**: Pure CSS (Vanilla CSS). This gives us maximum flexibility to build custom animations and layouts without being constrained.

## Sections / Components

### 1. Hero Section
- A bold, eye-catching introduction.
- Highlights: "Mokshith Sanga", contact links (GitHub, LinkedIn, Email).
- A playful, animated summary that presents you as an "Analytical and product-focused professional."

### 2. Experience Timeline
- An interactive, scrollable timeline or a stack of cards highlighting your professional background.
- Focus: **DeftRonin Technologies** & **SysTools Pvt. Ltd**.
- Key metrics and impact (e.g., 93% clinician adoption, reduced unit cost by 43%) will be highlighted in bold, colorful tags.

### 3. UK Work Experience (Placeholder)
- A dedicated, stylistically distinct section ready for your current part-time UK work.
- Designed so you can easily plug in the details later without breaking the layout.

### 4. Projects Showcase
- A dynamic grid or carousel for your projects:
  - **Stance Dashboard (B2B)**
  - **Malware Development (Windows OS)**
  - **Smart Parking System (IoT)**
- Each card will have a hover effect revealing the tech stack used.

### 5. Skills "Galaxy" or Layout
- A visual representation (floating bubbles, progress bars, or a web grid) of your technical skills:
  - Python, SQL, JavaScript
  - MongoDB, MySQL
  - Figma, Uizard, LoveableAI, Postman, JIRA
  - Various testing methodologies
